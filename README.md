# 月明·朋友圈文案

把观点、方法或真实经历写成符合月明语气的朋友圈文案，用具体内容展开个人判断。

## 你会得到什么

- 以观点或方法为主的朋友圈文案
- 与当前内容对应的主图需求
- 适用于当前作品的文案文件

## 试着这样说

```text
用 moonlit-wechat-moments。把这篇文章里最值得分享的观点写成一条朋友圈，保留我的口吻，用具体案例展开，配一张有信息作用的图。
```

## 安装与首次使用

将本仓库的完整目录交给支持本地 Skill 的 Agent 安装，保留 `SKILL.md` 与随附资源。已有同名版本时先检查差异；使用版本锁的工作区沿用自身升级机制。

让 Agent 安装：

```text
请安装这个 Skill：https://github.com/zzyong24/moonlit-wechat-moments
```

也可通过 Skills CLI 安装：

```bash
npx skills add zzyong24/moonlit-wechat-moments
```

## 配置与依赖

需要原始材料、当前品牌规范和作者语气；可接收已有文章或选题引擎的结果。当前默认偏向 200–500 字观点或方法型内容。需要图片时另行提供素材或生图能力。

## 数据与使用边界

文本由当前 Agent 处理，生图按实际选用的能力执行。短金句型可按需使用外部 pengyouquan，需自行安装并核对来源。本 Skill 交付文案，不操作个人微信发布。
